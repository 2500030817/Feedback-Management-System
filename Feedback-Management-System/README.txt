HOW TO RUN
1. Extract the ZIP file.
2. Open the Feedback-Management-System folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the localhost link shown in the terminal.

NOTES
- User signup and login details are saved in Local Storage.
- Feedback is also saved in Local Storage in this version.
- Local Storage data stays in the same browser/device; it does not automatically sync to other devices.
- This is a classroom demonstration. Plain-text Local Storage passwords and frontend demo admin credentials are not secure for a real production system.
